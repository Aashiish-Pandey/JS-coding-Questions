
Given an object with a cycle, remove the cycle or circular reference from it.

Object with a cycle

Example
Input:
const List = function(val){
  this.next = null;
  this.val = val;
};

const item1 = new List(10);
const item2 = new List(20);
const item3 = new List(30);

item1.next = item2;
item2.next = item3;
item3.next = item1;

// this forms a cycle, if you console.log this you will see a circular object, 
// like, item1 -> item2 -> item3 -> item1 -> so on.

Output:
// removes cycle
// item1 -> item2 -> item3

This is a **linked list cycle removal** problem (very common in JS interviews).
Here the object isn’t a generic object graph — it’s a **singly linked list with a loop**.

---

## 🔍 Problem Recap

You have a linked list:

```js
item1 -> item2 -> item3
              ↑       |
              └───────┘
```

Goal: **remove the cycle**, so it becomes:

```js
item1 -> item2 -> item3 -> null
```

---

## ✅ Correct & Interview-Standard Solution

### Using **Floyd’s Cycle Detection Algorithm** (Tortoise & Hare)

This is the **expected solution** in interviews.

---

## Step-by-step approach

1. Detect if a cycle exists
2. Find the **start node of the cycle**
3. Break the cycle by setting the previous node’s `next = null`

---

## ✅ Implementation

```js
function removeCycle(head) {
  let slow = head;
  let fast = head;

  // Step 1: Detect cycle
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;

    if (slow === fast) {
      break;
    }
  }

  // No cycle
  if (!fast || !fast.next) {
    return head;
  }

  // Step 2: Find start of cycle
  slow = head;
  let prev = null;

  while (slow !== fast) {
    prev = fast;
    slow = slow.next;
    fast = fast.next;
  }

  // Step 3: Break the cycle
  prev.next = null;

  return head;
}
```

---

## 🧪 Example Usage

```js
const List = function (val) {
  this.next = null;
  this.val = val;
};

const item1 = new List(10);
const item2 = new List(20);
const item3 = new List(30);

item1.next = item2;
item2.next = item3;
item3.next = item1; // cycle

removeCycle(item1);

// Result:
// item1 -> item2 -> item3 -> null
```

## 🧠 How This Works (Interview Explanation)

### Why Floyd’s Algorithm?

* Uses **two pointers**
* **O(n)** time
* **O(1)** extra space (no Set / Map)

### Key insight:

When slow and fast meet:

* Reset `slow` to `head`
* Move both one step at a time
* They meet at **cycle start**
* Keep track of `prev` to break the loop

## ⭐ Bonus: Set-based (Simpler but not optimal)

```js
function removeCycleWithSet(head) {
  const seen = new Set();
  let curr = head;
  let prev = null;

  while (curr) {
    if (seen.has(curr)) {
      prev.next = null;
      break;
    }
    seen.add(curr);
    prev = curr;
    curr = curr.next;
  }
}
```
