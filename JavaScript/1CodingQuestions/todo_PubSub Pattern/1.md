
# 🧠 What is Pub-Sub / Observer Pattern?

**Observer pattern (Pub/Sub)** means:

> One object (**Publisher / Subject**) keeps a list of other objects (**Subscribers / Observers**) and **notifies them automatically** when something happens.

### Key idea

* **Publisher doesn’t know who subscribers are**
* Subscribers just “listen”
* This creates **loose coupling**

---

# 🧩 Real-life analogy

📢 **YouTube Channel**

* Channel = **Publisher**
* Users = **Subscribers**
* New video = **Event**
* All subscribers get notified

---

# 🧱 Core Components

### 1️⃣ Publisher (Host / Subject)

* Maintains subscriber list
* Allows:

  * `subscribe`
  * `unsubscribe`
* Notifies subscribers

### 2️⃣ Subscriber (Observer)

* Just a function
* Gets called when event happens

---

# 🧠 Why JavaScript Uses This Pattern Everywhere

JavaScript is **event-driven**:

```js
button.addEventListener("click", handler);
button.removeEventListener("click", handler);
```

This is **exactly pub-sub**:

* `button` → publisher
* `handler` → subscriber
* `click` → event

# ✅ Your Code Explained Line-by-Line

### Publisher (`Move`)

```js
const Move = function () {
  this.handlers = [];
```

👉 `handlers` stores all subscribers (observer functions)

---

### Subscribe

```js
this.subscribe = function (fn) {
  this.handlers.push(fn);
};
```

👉 Adds observer to the list

---

### Unsubscribe

```js
this.unsubscribe = function (fn) {
  this.handlers = this.handlers.filter(item => item !== fn);
};
```

👉 Removes a specific observer

---

### Notify / Fire Event

```js
this.fire = function (o, thisObj) {
  const scope = thisObj || window;
  this.handlers.forEach(item => {
    item.call(scope, o);
  });
};
```

👉 Calls **every subscriber** with:

* Event data (`o`)
* Optional context (`thisObj`)

# ⚠️ Issues in Your Implementation (Interview Notes)

### 1️⃣ Possible duplicate subscriptions

```js
subscribe(fn) {
  this.handlers.push(fn); // duplicates allowed
}
```

👉 Use `Set` instead of array to avoid duplicates.

---

### 2️⃣ `window` dependency

Better to avoid `window` in Node / SSR.

---

# ✅ Improved (Interview-Perfect) Version

```js
class Observable {
  constructor() {
    this.handlers = new Set();
  }

  subscribe(fn) {
    this.handlers.add(fn);
    return () => this.handlers.delete(fn); // unsubscribe helper
  }

  notify(data) {
    this.handlers.forEach(fn => fn(data));
  }
}
```

# 🧠 Interview One-Liner Answer

> The Observer (Pub-Sub) pattern allows objects to subscribe to events and get notified automatically, enabling loose coupling and event-driven design.

# 🔥 Difference: Observer vs Pub-Sub (Advanced)

| Observer         | Pub-Sub         |
| ---------------- | --------------- |
| Direct reference | Event channel   |
| Tighter coupling | Looser coupling |
| Synchronous      | Often async     |
