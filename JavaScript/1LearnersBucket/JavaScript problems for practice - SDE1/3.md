# 📘 **JavaScript Arrays: Pass-by-Reference Cheat Sheet**

## 🔹 **1. Arrays are Objects**

In JavaScript, arrays are objects and variables store **references**, not the actual array data.

```js
const a = [1, 2, 3];  // a → reference to array in memory
```

---

## 🔹 **2. Passed by Value (of the Reference)**

JavaScript always passes arguments **by value**.
For arrays/objects, the **value** is the **reference** itself.

This behavior is known as:

### 👉 **Pass-by-Sharing**

Meaning:

* Both variables point to the **same object**
* Changing the object changes it for everyone
* Reassigning the reference does NOT

---

## 🔹 **3. Mutations Affect the Original**

```js
function modify(arr) {
  arr.push(4);
}

const a = [1, 2, 3];
modify(a);

console.log(a);  
// [1, 2, 3, 4]   ← changed
```

Because both `arr` and `a` refer to the **same array**.

---

## 🔹 **4. Reassignments Do NOT Affect the Original**

```js
function reassign(arr) {
  arr = [99, 100];  // new reference (local only)
}

const a = [1, 2, 3];
reassign(a);

console.log(a);
// [1, 2, 3]  ← unchanged
```

The original reference remains untouched.

---

## 🔹 **5. Key Rules (Easy to Remember)**

### ✅ Mutating the array → affects original

* `arr.push()`
* `arr.pop()`
* `arr[index] = ...`

### ❌ Reassigning the argument → no effect

* `arr = []`
* `arr = newArr`

---

## 🔹 **6. Summary Table**

| Operation Type | Example        | Affects Original?              |
| -------------- | -------------- | ------------------------------ |
| Mutate content | `arr.push(10)` | ✅ Yes                          |
| Mutate index   | `arr[0] = 99`  | ✅ Yes                          |
| Reassign local | `arr = []`     | ❌ No                           |
| Reassign outer | `a = []`       | — (changes only your variable) |

---

## 🔹 **7. Final Takeaway**

### ✔ Arrays appear pass-by-reference

### ✖ But technically **“references are passed by value”**

### ✔ Mutations persist

### ✖ Reassignments do not
